# 工资核算系统

一个简单易用的桌面工资核算系统，专为 HR 设计。

## 功能

- 员工管理：添加、编辑、删除员工
- 考勤管理：Excel 批量导入考勤数据
- 绩效管理：支持自定义公式计算绩效奖金
- 工资核算：自动计算工资，包含社保、公积金、个税
- 报表导出：一键导出 Excel 工资表

## 安装

```bash
pip install pandas openpyxl
使用
python main.py
功能说明
1. 员工管理
点击"添加员工"按钮填写员工信息
工号必须唯一
可以设置社保、公积金、医保等扣款比例
2. 考勤管理
点击"生成模板"下载 Excel 模板
填写考勤数据后，点击"导入考勤"上传
3. 绩效管理
点击"生成模板"下载 Excel 模板
填写绩效数据后，点击"导入绩效"上传
奖金公式支持：base_salary（基本工资）、score（绩效分数）等变量
4. 工资核算
选择年份和月份
点击"计算工资"自动计算
点击"导出工资表"下载 Excel 文件
注意事项
社保比例为 0-1 之间的小数（0.08 = 8%）
个人所得税采用简化计算，实际请使用税务系统
建议定期备份数据库文件
